\section{\texorpdfstring{$\omega$}{omega}-limit sets}

The points a curve or sequence returns arbitrarily close to, arbitrarily late: its cluster
points at infinity, which is the $\omega$-limit of topological dynamics for a single orbit.

\chapter{Systems}

The most general systems the library considers are $\dot x = F(t, x, u)$ in continuous time and
$x^{+} = F(k, x, u)$ in discrete time, each with an output $y = h(t, x, u)$. As for the linear
systems of the next chapter, there is one object per time domain: the data has the same shape, but a continuous
trajectory is an integral curve and a discrete one is a recursion.

Special cases are constructors on the general object, each with a predicate recognising it:
\emph{time invariance} drops $t$, and \emph{autonomy} drops $u$. Autonomy is used here in the
control-theory sense, \emph{without input}; much of the dynamical-systems literature uses the word
for time invariance instead.

\chapter{Linear systems}

\section{The linear system objects}

Linear systems are a special case of the general systems of the Systems chapter: the
continuous-time system with $F(t, x, u) = A(t)x + B(t)u$ and $h(t, x, u) = C(t)x + D(t)u$, and its
discrete-time counterpart. The objects below carry only the coefficient data. Each is the input of
a constructor into the general system, and the semantics --- state equation, output equation,
trajectories --- are defined through that constructor, so every result about general systems
applies to linear ones unchanged.

There are two objects per time domain: a \emph{linear time-varying} (LTV) system with coefficient
maps $A(t), B(t), C(t), D(t)$, and a \emph{linear time-invariant} (LTI) system with constant
matrices. An LTI system is not a different kind of system: it builds the LTV system with constant
coefficients, and the general system it describes is the time-invariant system of the Systems
chapter, by definition.

\section{Peano--Baker series and the state transition matrix}

matrix $\Phi(t,t_0)$ as the Peano--Baker series and proves Theorem 5.1: $\Phi$ solves the
